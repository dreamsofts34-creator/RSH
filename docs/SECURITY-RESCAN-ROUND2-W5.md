## 2. Dobara verify — band rehte hain (Round 1 fixes barkarar)

- **WebOTA:** har endpoint par `authenticate()` (root, `/update` completion samet, not-found) + 5-fail/60 s lockout + per-boot random CSRF token (`X-RSH-CSRF`, constant-time compare) — `firmware/rsh/webota.cpp`. CSRF token sirf authenticated page se milta hai.
- **Signed OTA:** board-side verify-before-apply (Ed25519, `Update.end()` sirf signature OK par; anti-downgrade running version se compare; magic 0xE9; size cap app partition) — `webota.cpp` + `ota_validate.h`. App-side `FirmwareImageValidator` signature verify karta hai (NSec, baked pubkey) — fingerprint **verify kiya: SHA-256 `387764a4…6411`, firmware `signing_pubkey.h` = C# baked key, barabar**. Release workflow `sign-image.py --verify` + signed-region SHA compare + raw bins par FAIL karta hai — `.github/workflows/release.yml:69-105,119-128`.
- **HMAC control:** dispatcher sirf ACCEPT par handler chalata hai (BAD_TAG/REPLAY/DUPLICATE kabhi execute nahi) — `firmware/rsh/ctrl.h`; counter RFC 1982 serial arithmetic, wrap-safe — `protocol.h`; 32-entry replay cache, idempotent fallback. KEY_RESET sirf BOOT-hold ≥10 s armed state mein (120 s window, expiry par reboot) — `safemode.h`, `ctrl_handlers.h`; SET_PASSWORD 0x0C length/charset (8..63, 0x21–0x7E) teen jagah — `password.h`, `ctrl_handlers.h`, `ControlClient.cs` (+60 s app-side rate limit, SEC-E-02). FACTORY_RESET key nahi wipe karta; RSTX hata diya gaya (restart sirf HMAC REBOOT 0x09).
- **Pairing:** 60 s window, sirf unpaired + window mein key/password HELLO mein (warna zero) — `net.cpp` net_build_hello_reply, `keystore.cpp`; first-boot random 32 B key (hardware RNG, weak-key check, 3 attempts) + 24-char password (rejection sampling, 57-symbol charset, ~140 bit) — `keystore.cpp`; keystore fail → AP up hi nahi (fail closed) — `rsh.ino` setup.
- **Secrets — DPAPI read path asal mein istemal hota hai (SEC-E-04/09 fixed, dobara verify):** `BoardSession.TryGetWifiPassword` → `KeyStore.TryLoadPassword`; `AppServices.GetWheelPassword` pehle KeyStore, phir in-memory buffer, `settings.json` se kabhi nahi; `WheelWifiPassword`/`LegacyWheelWifiPassword` dono `[JsonIgnore]`; migration pehle HELLO par + disk wipe agle Save par; rotation purge (nayi key → purana password mit ta hai); blob atomic write + 64 KB cap; `WipeSessionKey`/`ForgetBoardCredentials` maujood. **NVS password obfuscated, not encrypted (SEC-E-01 PARTIAL, unchanged):** `wifipw2` (device-key keystream XOR, `pw_obfuscate.h`), legacy `wifipw` pehli load par migrate + mit ta hai; **device key khud NVS mein plaintext hai** — asal hal OPEN-3 hai (§3).
