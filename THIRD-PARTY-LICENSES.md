## 0. Policy — what may ship

- **Allowed (Rust, `deny.toml` allow-list):** MIT, Apache-2.0, Apache-2.0 WITH LLVM-exception,
  BSD-2-Clause, BSD-3-Clause, ISC, Unicode-3.0, Unicode-DFS-2016, Zlib, MPL-2.0 (see §1.2).
- **Denied:** every other license, **including all strong copyleft (GPL/AGPL/LGPL)** — a crate
  whose only license is GPL/AGPL/LGPL does not ship. A crate that is *dual/triple*-licensed
  with a copyleft option **and** a permissive option ships under the permissive option
  (see §1.3 — the copyleft terms are never the ones taken).
- **Frontend + sidecar policy (same rule, no separate allow-list file):** permissive only,
  no GPL/AGPL/LGPL anywhere in the tree. Verified below — none present.
- **Enforcement:** `cargo deny check` (CI `audit` job) + `npm audit --audit-level=high`
  (CI `frontend` job). The release workflow regenerates all three SBOMs fresh at release
  time (`.github/workflows/release.yml`) — the committed SBOMs are the H4 snapshot.

(`cargo tree -p rsh-app --target x86_64-pc-windows-msvc`, 299 packages):

## 4. Not bundled / not distributed by RSH (excluded from the SBOMs)

| Item | Why excluded |
|---|---|
| **vJoy driver** (BrunnerInnovation 2.2.2.0) | **Never bundled** (decision D18). The user installs it separately; the app only resolves it via registry → Program Files at runtime and shows a download link when missing. Its license therefore does not enter RSH's distribution. |
| **WebView2 runtime** | Ships with Windows 10/11; the installer downloads the bootstrapper if missing (`bundle.windows.webviewInstallMode`). Microsoft component, not RSH's to license. |
| **NSIS / WiX toolsets** | Build-time only (fetched by the Tauri bundler on the Windows build machine). |
| **.NET 10 SDK** | Build-time only (sidecar AOT publish). The AOT exe is self-contained. |
| **Firmware C++ libraries** (Arduino core, ESP32 Arduino framework) | The firmware ships as a binary built from `reference/firmware-v4.0.1/`; its third-party notices live in that tree. The Rust app SBOM does not cover firmware libraries — a firmware SBOM is out of scope for H4 (firmware is unchanged v4.0.1). |
